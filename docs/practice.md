# Каталог из practice

Единственный встроенный каталог сформирован из четырёх предоставленных DOCX.
Условия заданий сохранены; технический формат NEXCODE добавлен отдельным разделом.
Цели, оборудование, примеры и контрольные вопросы доступны в оригиналах DOCX.

| Документ | Тема | Задания |
|---|---|---:|
| ЯП_ЛР1,2.docx | Словесные и табличные алгоритмы, блок-схемы | 12 |
| ЯП_ЛР3,4.docx | Переменные, типы, условия и циклы | 23 |
| ЯП_ЛР5_6.docx | Функции, процедуры, списки и словари | 24 |
| ЯП_ЛР7,8.docx | Файлы и исключения | 13 |

Всего 72 задания: 45 с автоматической проверкой, 14 программ со свободными
данными и проверкой преподавателем, 13 письменных. Варианты 3.7 А и Б работы 3–4
представлены отдельно. Контрольные вопросы не превращены в дополнительные задачи.

Письменные работы сохраняются и сдаются преподавателю. Для блок-схем поддерживается
Mermaid: начните ответ с `flowchart TD` либо вставьте блок mermaid. Предпросмотр
не выставляет оценку. Преподаватель проверяет требования, таблицы и структуру кода.

Автотесты проверяют результат, а не наличие конкретного синтаксиса функции,
рекурсии, break или continue. Соблюдение этих учебных требований проверяет преподаватель.
Тесты и форматы платформы не являются официальными критериями оценивания кафедры.

## Файлы

Python open() работает с текстовыми файлами в памяти отдельного запуска.
Поддерживаются r, w, a, x и варианты с +, UTF-8, чтение построчно, read/write,
readlines/writelines, with, os.path.exists() и базовые операции pathlib.Path.
Можно создавать файлы с простыми относительными именами. Пути сервера, каталоги,
сеть и системные процессы недоступны. Между тестами учебные файлы сбрасываются.
Исходные файлы и созданные отчёты видны в интерфейсе. Для файловых автотестов
проверяются и stdout, и содержимое ожидаемых файлов.

Выполнение по кнопке «Запустить» использует файлы первого примера. Для задач со
свободными данными запускайте свою программу, создающую файлы, и сдавайте код
преподавателю.

## Пересборка каталога

```sh
python scripts/build-practice.py
```

Скрипт проверяет покрытие всех исходных пунктов, генерирует встроенный JSON,
каталог предварительного просмотра и копии DOCX для скачивания. Проверочные
суммы исходников записаны в practice/manifest.json, файл practice/catalog.json
совместим с импортом через интерфейс. Повторный ручной импорт добавит дубликаты;
для штатного обновления используйте пересборку и перезапуск backend.

Синхронизация выполняется один раз на версию содержимого. Идентификаторы заданий,
черновики и отправки сохраняются, старый каталог скрывается из текущего прогресса.
При обычном перезапуске изменения преподавателя сохраняются. Перед обновлением
делайте резервную копию SQLite. SEED_PRACTICE=true включает штатную синхронизацию.
