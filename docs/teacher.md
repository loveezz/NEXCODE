# Руководство преподавателя

## Ученики и доступ

Студент входит по ФИО и группе, без регистрации и пароля. Преподаватель использует отдельный `/staff/login`; служебный аккаунт настраивает администратор через bcrypt-конфигурацию.

В разделе «Группы и вход»:

1. Укажите дату окончания семестра и сохраните настройки. Изменение применится к текущим ученическим сессиям.
2. Выберите свободный ввод группы или только выбор из справочника.
3. Создайте группы; при необходимости включите индивидуальные коды.
4. Откройте «Список и коды», вставьте строки `ФИО;КОД` либо загрузите [JSON](../examples/invites.json).
5. Выдайте каждому студенту его код. Разные коды различают полных тёзок.

Переход на вход с кодами завершает старые сессии группы. «Завершить сессии» под карточкой группы отзывает доступ на всех устройствах, сохраняя прогресс. Для отдельного студента откройте «Студенты → Журнал входов» и используйте кнопку завершения его сессий. Во вкладке «Журнал входов» можно фильтровать группу и просматривать предыдущие страницы; записываются успехи и отказы, время и IP.

Полная схема и особенности миграции старых пользователей в группу АРХИВ: [подсистема входа](identity.md).

## Лабораторные и упражнения

В «Каталог заданий» создайте лабораторную с названием, описанием и порядком. В её карточке нажмите «Упражнение»: задайте условие, шаблон Python, тесты JSON Lines, время и память. Условия — обычный текст, HTML не исполняется. Программа должна читать input() и выводить print(), без обращений к файлам и сети.

Для массовой загрузки используйте [examples/catalog.json](../examples/catalog.json) и кнопку «Импорт JSON» (до 2 МБ). Импорт проверяет весь документ и выполняется одной транзакцией; он добавляет новые работы, а не обновляет старые. Повторный импорт каталога создаст новые работы. Для редактирования используйте карандаш. «Скачать каталог» экспортирует условия, шаблоны и тесты без персональных данных.

Встроенный каталог взят из четырёх DOCX в папке practice: 72 задания из работ 1–2, 3–4, 5–6 и 7–8. Демо-работы архивируются при обновлении; их отправки и черновики сохраняются. Оригиналы документов доступны в карточках лабораторных. [Состав и форматы](practice.md).

Формат задания выбирается при редактировании: Python с автотестами, Python с проверкой преподавателем или письменный ответ. Для письменного ответа поле тестов можно оставить пустым. Свободные программы можно запускать, а затем сдавать преподавателю. Алгоритмы, таблицы и блок-схемы сдаются текстом; схемы Mermaid отображаются в предпросмотре.

В «Истории отправок» выберите «Ждут преподавателя», откройте отправку, оставьте комментарий и нажмите «Зачесть» либо «На доработку». Только зачтённая работа учитывается как решённая. Ожидание проверки не имитирует успешные автотесты. Упражнение с отправками удалять нельзя, чтобы сохранить историю.

## Прогресс

«Студенты» показывает ФИО, группу, количество решений и статусы каждого упражнения. «Отправки» открывает историю выбранного студента: код, stdout/stderr, сравнение тестов, замечания Ruff и время. Статус с замечаниями считается решённым; последующая неудачная попытка не отменяет прежнего решения. Обычный запуск без автотестов не засчитывается.

«Экспорт CSV» выгружает пары студент/упражнение, включая не начатые. Первые поля — student_id, full_name, group_name. UTF-8 BOM помогает табличным редакторам; значения, похожие на формулы, экранируются.

Автотесты и технические форматы NEXCODE — внутренние механизмы и не являются официальными критериями оценивания кафедры.
