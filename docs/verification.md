# Проверка реализации

## Netlify — 17 ноября 2026

На сообщённом сайте главная возвращала 404, а /README.md — 200 с исходным README репозитория: опубликована папка исходников вместо статической сборки. Добавлены netlify.toml и build:netlify с корневым basePath, отключением серверного адаптера и проверкой наличия out/index.html.

Сборка Netlify прошла. Браузерная проверка на обычном статическом сервере без префиксов подтвердила главную, каталог, query-навигацию/перезагрузку редактора, локальный Monaco, отсутствие ошибок JavaScript и запросов к отсутствующему API. Проверены 1440/1024 px, _headers/_redirects и архив с index.html непосредственно в корне. Архив для ручного деплоя сохранён локально в artifacts/NEXCODE-netlify.zip.

## Интерфейс и GitHub Pages — 17 ноября 2026

Увеличены шрифты во всём интерфейсе: основной текст 17 px, меню 16 px, формы 16 px, заголовок страницы 34 px, Monaco 16 px. Проверены ширины 1440 и 1024 px без горизонтального переполнения.

Успешны обе сборки: обычная standalone и статический export для GitHub Pages. Браузерная проверка статического сайта под `/NEXCODE/` подтвердила каталог, query-ссылки упражнений, перезагрузку редактора, локальную загрузку Monaco и режим без сохранения/запуска. В предварительном просмотре выполнено **0 запросов к API**, ошибок JavaScript нет. Вход и выполнение отключены явно, сайт не подделывает работу сервера.

Дата: 16 ноября 2026. Windows, Go 1.27.4, Node.js 24, Python 3.12, Chrome. Docker в этой среде отсутствует.

Проверки актуальной подсистемы идентификации:

- Go-тесты: нормализация Unicode/пробелов/регистра, длина в символах, запрет невидимых дублей.
- Параллельные входы: один профиль и 24 независимых UUIDv4-сессии; cookie Secure/httpOnly/SameSite=Lax; UUID не пишется в технический журнал.
- Разные браузеры видят один черновик; выход завершает только свою сессию. Истёкшие сессии и завершённый семестр запрещают вход.
- Индивидуальные коды, полные тёзки, единые ответы отказа, сохранение черновика при включении кодов, запрет неоднозначного отключения кодов.
- Преподаватель меняет дату и режим групп, отзывает сессии; журнал фильтруется. Лимит 10 попыток/мин/IP и отказ от недоверенного forwarded IP.
- Разделение staff/student, bcrypt-конфигурация, защита последнего администратора, отзыв служебных сессий при смене пароля.
- Миграция legacy SQLite с резервной копией, сохранением ID, отправок и черновиков, переносом служебных хэшей и удалением JWT/студенческих паролей из рабочей схемы. Повторное открытие безопасно.
- Сохраняются проверки движка JSON Lines, отдельных expected/actual, ролей, CSRF, транзакционного импорта и сохранности истории.
- Production-сборка Next.js, TypeScript и go vet.

Браузерные тесты работают на отдельной тестовой БД и проверяют реальный Go API/SQLite/Monaco. Финальный прогон: **3 passed (11,9 с)**. Проверены ученический вход без пароля и повторное восстановление профиля; преподавательская дата, коды, полные тёзки, несколько браузеров, журнал и очистка сессий; каталог, CSV и администрирование.

Технический slog-журнал проверен отдельно: 120 JSON-записей, включая 9 входов (8 успехов и 1 отказ); во всех событиях входа присутствуют время, IP, ФИО, группа и результат. `npm audit` — 0 уязвимостей, `govulncheck` — No vulnerabilities found. Синтаксис Compose и примеры JSON проверены; наружу опубликован только gateway. В текущей .env открытый ADMIN_PASSWORD заменён bcrypt-хэшем того же пароля.

Docker Compose, входной gateway и настоящая Python-песочница здесь не запущены: нужны Docker-хост и контейнерные тесты. Времена исполнения 2 с / 10 с и нагрузка 30 пользователей с кодом не подтверждены. Прежний локальный замер чтений каталога (p95 78 мс для 30 аккаунтов) относится к API предыдущей версии и не подтверждает новую авторизацию или производительность контейнеров.

Четыре исходные лабораторные пользователь добавит позднее. Подготовлены демонстрационный каталог, редактор и импорт; это согласованная граница наполнения.
